# Micasa Sucasa Logistics & Equipment Limited Website

Static responsive website for **mslogisticsandequipment.com**.

## Files
- `index.html`
- `styles.css`
- `script.js`

## Deploy on GitHub Pages
1. Create a new GitHub repository.
2. Upload these files to the repository root.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. Add your custom domain `mslogisticsandequipment.com` in GitHub Pages settings after your DNS is pointed to GitHub Pages.
